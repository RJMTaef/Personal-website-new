# Roslan Taef — personal portfolio

A responsive portfolio focused on data engineering, analytics, and practical automation. Built with Next.js App Router, React, TypeScript, and CSS, with Lucide icons.

## Development

Use Node.js 20 or later. Install with `npm ci`, then run `npm run dev`. The production build is `npm run build`; `npm run start` serves it. Run `npm run typecheck` for TypeScript checks.

## Editing content

`src/data/portfolio.ts` holds the specialties, toolkit, project descriptions, destinations, and contact details. Section components live in `src/components/`; the design and responsive rules are in `src/app/globals.css`.

The project gallery has three filters. Each card includes expandable implementation notes and a link to its real repository or live application. Project diagrams are illustrative; they do not represent live traffic, measured results, or actual banking records. Banking projects use synthetic data. CDTI links to its public application; its private repository is not exposed.

The contact section uses direct email and a clipboard action. It does not pretend to submit a form. Add a resume download only when a real PDF is included.

## Content decisions

The redesign removes grades, outdated co-op dates, placeholder testimonials, unverified employers, unsupported performance metrics, missing download assets, and incorrect repository URLs. Education is described as background without asserting a current enrollment or graduation date. No job title, employer relationship, or proficiency rating is invented.

## Preview and deployment

The existing deployment is associated with `RJMTaef/Personal-website-new` and `https://personal-website-new-nine.vercel.app`. Preserve this repository and hosting setup. A local build or preview does not update production. If the canonical domain changes, update `metadataBase` in `src/app/layout.tsx`, `public/robots.txt`, and `public/sitemap.xml` together.

Social preview artwork is generated by `src/app/opengraph-image.tsx`; the favicon is `src/app/icon.svg`. No third-party fonts or analytics are loaded by the new interface.
